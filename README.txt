Centralized admin panel for all DevBrothers plugins.

== Description ==

DevBrothers Admin Panel is a base plugin for managing the DevBrothers plugin ecosystem. It provides:

* Single access point to all DevBrothers plugins
* Beautiful and intuitive interface
* Centralized settings management
* Information dashboard with statistics
* Automatic integration with other DevBrothers plugins

== Installation ==

1. Upload the `devbrothers-admin-panel` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to the 'DevBrothers' menu to access the admin panel

== Frequently Asked Questions ==

= What does this plugin do? =

This plugin creates a centralized admin panel for all DevBrothers plugins, simplifying navigation and configuration.

= Is this plugin required for other DevBrothers plugins to work? =

Yes, all DevBrothers plugins require DevBrothers Admin Panel to be installed for proper operation. The plugin automatically detects and integrates installed DevBrothers plugins.

= What DevBrothers plugins are available? =

Current plugins in the DevBrothers ecosystem:
- DevBrothers Cyrillic URL - automatic transliteration of Cyrillic URLs
- DevBrothers Simple Translator - instant website translation via Google Translate
- Other plugins in development
